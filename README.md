A comprehensive collection of C programming assignments completed as part of the **Fundamentals of Data Structures Laboratory (FDSL)** course during my Bachelor of Technology (B.Tech) in Computer Science Engineering at **Sanjivani College of Engineering, Kopargaon**. This repository represents my practical learning journey in Data Structures and Algorithms using the C programming language. Every assignment was implemented during laboratory sessions to strengthen my programming fundamentals, logical thinking, and problem-solving abilities. The repository demonstrates my understanding of core data structures, algorithm implementation, modular programming, and software development practices. It serves as both an academic record and a valuable reference for students learning Data Structures.
